Команда создания топика:

docker compose exec kafka1 kafka-topics.sh \
  --create \
  --topic my-topic \
  --partitions 3 \
  --replication-factor 2 \
  --bootstrap-server localhost:9092


Подробная информация о топике:

docker compose exec kafka1 kafka-topics.sh \
  --describe \
  --topic my-topic \
  --bootstrap-server localhost:9092
